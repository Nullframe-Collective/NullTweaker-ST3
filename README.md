# NullTweaker

Configuration Editor for: 
- [CustomMapsFramework](https://github.com/Nullframe-Collective/CustomMapsFramework-ST3)
- [CustomNPCFramework](https://github.com/Nullframe-Collective/CustomNPCFramework-ST3)
- [CustomWeaponsFramework](https://github.com/Nullframe-Collective/CustomWeaponsFramework-ST3)
- [CustomPlayerCustomization](https://github.com/Nullframe-Collective/CustomPlayerCustomization-ST3)

Based on Vantablack: Map Tweaker, Weapon Tweaker, NPC Tweaker.
