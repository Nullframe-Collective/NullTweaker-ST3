# Framework contract snapshots

These source files are copied from the corresponding NullFrame framework projects for configuration compatibility tests. Each subdirectory includes its original MIT license. They are compiled only by the checks project; the editor itself has no dependency on game assemblies or framework repositories.

FrameworkStubs.cs supplies the Unity/game types needed by these data contracts. This verifies JSON serialization and descriptor validation, not Unity asset loading or in-game behaviour. Refresh these snapshots when framework formats change.
